# คู่มือผู้ดูแลระบบสูงสุด
SUPER_ADMIN สามารถอ่านคู่มือการใช้งานทุกบทบาท และใช้เมนูผู้ดูแลระบบสูงสุดเพื่อบริหารบัญชีผู้ดูแลตามสิทธิ์ของแพลตฟอร์ม. การเปลี่ยนบทบาทต้องตรวจบัญชีผ่าน LINE identity และการยืนยันสิทธิ์ฝั่ง Backend.
การอ่านคู่มือทุกบทบาทไม่เท่ากับได้รับอนุญาตดูข้อมูลส่วนตัวของผู้เช่าหรือยอดเงินของทุกองค์กรอัตโนมัติ. ข้อมูลจริงที่ระบุตัวบุคคลต้องใช้ขั้นตอน authorization ขององค์กรและ LINE identity ที่ถูกผูกอย่างถูกต้อง.
API token, secret, password, environment variables, private keys, internal infrastructure, customer identifiers ไม่ใช่เนื้อหาที่ Chatbot มีสิทธิ์ค้นหาหรือเปิดเผย.
