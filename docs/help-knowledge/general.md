# คู่มือการใช้งานระบบหอพัก — ข้อมูลทั่วไป
Apartment Platform เป็นระบบบริหารหอพักหลายอาคาร มีหน้าเข้าสู่ระบบและเมนูแยกตามสิทธิ์ผ่านเว็บ/LINE LIFF. ผู้ใช้สามารถติดต่อเจ้าของหอพักเพื่อขอสิทธิ์ เพิ่มบัญชี หรือแก้การผูกบัญชี LINE. เมนูจะแสดงตามสิทธิ์จริง ผู้ใช้ไม่สามารถเพิ่มสิทธิ์ด้วยการพิมพ์คำสั่งในแชท.
หากเข้าระบบไม่ได้ ให้ตรวจว่าบัญชี LINE ที่ใช้ตรงกับบัญชีที่ผูกไว้ เปิดจาก LINE Rich Menu และลองเข้าสู่ระบบใหม่. หากไม่เห็นเมนูที่ต้องการ ให้ตรวจบทบาทที่ได้รับจากเจ้าของหอพัก ไม่ใช้รหัสผ่านหรือโทเคนในแชท.
เมื่อเกิดปัญหาการใช้งานให้ระบุชื่อหน้าจอ ขั้นตอน และข้อความผิดพลาด โดยไม่ส่งรหัสผ่าน โทเคน หรือหลักฐานการเงินที่มีข้อมูลอ่อนไหว.
ระบบมีงานหลัก: ห้องพัก สัญญาเช่า อัตราค่าเช่า มิเตอร์น้ำไฟ ออกบิล รายการชำระเงิน เงินประกัน แจ้งซ่อม พนักงาน/สิทธิ์ รายงาน และแจ้งเตือน LINE. แต่ละหน้าจอต้องมีสิทธิ์และข้อมูลที่ถูกต้องก่อนใช้งาน.
