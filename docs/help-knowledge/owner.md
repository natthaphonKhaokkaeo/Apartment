# คู่มือเจ้าของหอพักและผู้ดูแล
จัดการหอพัก: เลือกอาคาร เพิ่มและแก้ไขห้องพัก ระบุหมายเลขห้อง ชั้น และสถานะ. ราคาเริ่มต้นค่าเช่า/ค่าน้ำ/ค่าไฟตั้งที่ระดับหอพัก และเลือกใช้ override เฉพาะห้องได้เมื่อราคาต่างกัน. การเปลี่ยนราคาอาจมีผลตามวันที่มีผลของอัตรา; การออกบิลต้องผ่านการตรวจสอบเพดานอัตราค่าน้ำไฟ.
จัดการสัญญา: บันทึกข้อมูลผู้เช่า วันเริ่มต้น-สิ้นสุด การเข้าพัก การย้ายออก และประวัติห้อง. ระบบตรวจสอบสัญญาที่ ACTIVE ก่อนออกบิล และต้องมีเลขมิเตอร์วันต้นรอบกับวันสิ้นรอบสำหรับน้ำและไฟ. หากระบบข้ามห้อง ให้ดูเหตุผล เช่น ไม่มีสัญญา ไม่ครบเลขมิเตอร์ หรือมีบิลรอบเดียวกันแล้ว.
ออกบิลรายห้องหรือออกเป็นชุด: เลือกอาคารและช่วงวันที่ กดคำนวณตัวอย่าง ตรวจยอดค่าเช่า น้ำ ไฟของแต่ละห้อง แล้วกดยืนยัน. บิลหลายห้องต้องให้ OWNER อนุมัติ. สามารถเริ่มรอบใหม่ได้ตลอด แต่ห้ามมีบิล ISSUED ซ้ำรอบเดียวกันหรือทับซ้อน.
แก้ไขและออกบิลใหม่: OWNER เปิดหน้าแก้ไขบิล เลือกบิล ISSUED ที่ยังไม่มีรายการชำระหรือหลักฐานโอน ใส่เหตุผลอย่างน้อย 15 ตัวอักษร ระบุยอดปรับเพิ่ม/ลดเป็นบาท แล้วตรวจสอบยอดใหม่ก่อนยืนยัน. ระบบจะยกเลิกฉบับเดิม เก็บประวัติ พร้อมออกบิลฉบับทดแทน หากมีรายการชำระแล้วต้องดำเนินการกับฝ่ายการเงิน ห้ามแก้โดยข้ามรายการชำระ.
การรับชำระ: ผู้เช่ายื่นหลักฐานโอน จากนั้นผู้มีสิทธิ์ตรวจสอบและอนุมัติหรือปฏิเสธการชำระ. รายการรับเงิน/ปรับปรุงการเงินมีการตรวจสอบแยกต่างหาก. การแนบสลิปไม่ใช่การยืนยันรับเงินอัตโนมัติ.
เงินประกัน: จัดการเงินประกันกับสถานะสัญญา การสรุปและการคืนเงิน รวมทั้งตรวจสอบยอดค้าง/ค่าปรับก่อนปิดสัญญา. เรื่องคืนเงินหรือกลับรายการการเงินจริงต้องดำเนินการผ่านขั้นตอนอนุมัติที่ระบบกำหนด.
รายงาน: ใช้หน้ารายงานเพื่อตรวจยอดบิล รายรับ ยอดค้าง สถานะห้อง และกิจกรรมการดำเนินงาน เลือกช่วงเวลาที่ต้องการและตรวจข้อมูลล่าสุดก่อนใช้ตัดสินใจ.
ออกบิลกระดาษโดยไม่ต้องเชิญผู้เช่า: เจ้าของหอพักเพิ่มสัญญาเช่าด้วยชื่อผู้เช่า ห้อง และวันเริ่มเช่าได้เลย ไม่ต้องมี LINE หรือตอบรับคำเชิญในระบบก่อน เจ้าของจดมิเตอร์น้ำและไฟของวันต้นรอบและปลายรอบ แล้วออกใบแจ้งหนี้ได้ตามปกติ ดาวน์โหลด PDF ไปพิมพ์ส่งเป็นกระดาษได้ ระบบไม่ส่ง LINE หากผู้เช่าไม่ได้ผูกบัญชีหรือไม่อนุญาตรับแจ้งเตือน
รูปมิเตอร์เป็นหลักฐานเสริมที่แนบได้ตามต้องการ ไม่บังคับแนบรูปตอนจดเลขมิเตอร์หรือออกบิล สามารถออกบิลด้วยเลขมิเตอร์ที่ครบตามรอบได้ บิลรายห้องหรือหลายห้องมีช่องข้อความเพิ่มเติมไม่เกิน 300 ตัวอักษร ใส่ข้อความเพื่อพิมพ์หมายเหตุบนเอกสารโดยไม่เพิ่มยอดเงิน
รายงานบิลรายห้องสำหรับ OWNER: เปิดเมนู รายงานบิลรายห้อง เลือกห้อง วันที่ และสถานะ ดูยอดเรียกเก็บ รับชำระ คงค้าง และประวัติ VOID/ฉบับแก้ไข กด ออกบิลใหม่ เพื่อไปหน้าการออกบิล กด แก้ไขและออกใหม่ เพื่อไปขั้นตอน Void & Reissue (บิลต้องไม่มีธุรกรรมชำระเงิน) กด เปิดเพื่อพิมพ์ ดู PDF ในเบราว์เซอร์ หรือ บันทึก PDF บันทึกรูป PNG แชร์บิล ผ่านแอปที่อุปกรณ์รองรับ หากแชร์ไม่ได้ระบบดาวน์โหลดไฟล์แทน ไม่มีลิงก์สาธารณะสำหรับบิลที่มีชื่อผู้เช่า
