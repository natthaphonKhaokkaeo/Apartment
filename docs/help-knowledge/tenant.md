# คู่มือผู้เช่า
ผู้เช่าใช้เมนูผู้เช่าเพื่อดูข้อมูลของสัญญาตนเอง บิลล่าสุด ยอดค้างชำระ วันครบกำหนด เอกสารใบแจ้งหนี้ และข้อมูลช่องทางชำระตามที่หอพักกำหนด. ต้องผูก LINE กับสัญญาที่ยังใช้งานอยู่จึงจะดูข้อมูลเฉพาะตนได้. ห้ามถามข้อมูลส่วนตัวของห้องหรือสัญญาของผู้อื่น.
เมื่อโอนเงิน ให้เปิดรายการใบแจ้งหนี้ เลือกใบแจ้งหนี้ที่ต้องการและยื่นหลักฐานการโอนตามขั้นตอน. การส่งสลิปไม่ใช่การยืนยันว่าได้รับเงินแล้ว ต้องรอผู้ดูแลตรวจหลักฐาน. ยอดเงินอาจเปลี่ยนหลังการตรวจอนุมัติหรือปรับปรุงรายการ.
ผู้เช่าร้องขอแจ้งซ่อมได้โดยระบุปัญหา รูปถ่าย และติดตามสถานะบนหน้าจอแจ้งซ่อม. สามารถเปิดดูประวัติการแจ้งซ่อมตามสิทธิ์ของตน.
หากบิลผิด ให้ติดต่อเจ้าของหอพักเพื่อขอแก้ไข; ผู้เช่าไม่มีสิทธิ์ออกบิลใหม่หรือยกเลิกบิลเอง. บิลที่ถูกยกเลิกจะไม่แสดงเป็นยอดค้างใหม่ แต่เก็บเป็นประวัติ.
การแจ้งเตือนผ่าน LINE ต้องมีการผูกสัญญาและยินยอมรับการแจ้งเตือนอย่างชัดเจน; หากไม่ได้รับข้อความ ให้ตรวจบัญชี LINE และการยินยอมก่อน.
