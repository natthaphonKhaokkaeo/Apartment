# คู่มือแจ้งเตือน LINE OA
การส่งแจ้งเตือนบิลผ่าน LINE OA ไม่ใช่การใช้ AI ตอบแชท: ระบบส่งตามเหตุการณ์ออกใบแจ้งหนี้และการถึงกำหนดชำระ.
ผู้ดูแลต้องตั้งค่า LINE OA และ Webhook ให้ถูกต้องก่อน จากนั้นผูก LINE ของผู้เช่ากับสัญญา ACTIVE และมีความยินยอมรับการแจ้งเตือนที่ยังไม่ถูกถอน. ออกบิลหรือรอรอบกำหนดส่งแล้วตรวจสถานะ Outbox และผลการส่งในหน้า LINE Operations.
หากแจ้งเตือนไม่ออก ให้ตรวจ LINE OA enabled, การผูกบัญชี, consent, โหมดการส่ง และคิวสถานะ/การส่งล้มเหลว. ห้ามนำ Channel Secret, Access Token หรือ API key ไปแชร์ในแชท. ต้องตั้งผ่านช่องทางตั้งค่าปลอดภัยของผู้ดูแลระบบ.
บิลเดิมที่แก้ไขหรือยกเลิกแล้วไม่ควรแจ้งเตือนเป็นยอดใหม่; ระบบจะสร้างเหตุการณ์แจ้งเตือนจากบิลฉบับทดแทนตามสิทธิ์และความยินยอม.
