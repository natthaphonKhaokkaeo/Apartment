# คู่มือพนักงานและผู้จัดการ
ผู้จัดการหรือพนักงานเข้าถึงเฉพาะอาคารและเมนูที่บทบาทหรือการมอบหมายอนุญาต. หน้าที่อาจรวมถึงดูข้อมูลห้อง รับแจ้งซ่อม ติดตามงาน บันทึกมิเตอร์ และช่วยตรวจสถานะงานตามสิทธิ์. การอนุมัติการออกบิลเป็นชุดและการปรับปรุงการเงินระดับ OWNER ไม่ได้ให้สิทธิ์โดยอัตโนมัติแก่ STAFF หรือ MANAGER.
หากใช้งานเมนูไม่ได้ ให้ติดต่อเจ้าของเพื่อตรวจบทบาทและการมอบหมายสิทธิ์ ไม่สามารถข้ามสิทธิ์โดยพิมพ์ขอใน LINE.
งานมิเตอร์: บันทึกค่ามิเตอร์น้ำและไฟในวันต้น/ปลายรอบ ต้องตรวจความถูกต้องของหลักฐานและการเปลี่ยนมิเตอร์ก่อนให้ผู้มีสิทธิ์ออกบิล.
งานแจ้งซ่อม: ดูคำขอของห้องที่ได้รับมอบหมาย อัปเดตสถานะงานและสื่อสารความคืบหน้าอย่างเหมาะสมโดยไม่เปิดเผยข้อมูลส่วนบุคคล.
